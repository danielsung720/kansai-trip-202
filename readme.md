# 關西五日自由行・旅遊說明書

一頁式旅遊說明書，前端用 Google Sheet 的 **gviz API** 即時讀取行程資料。
編輯試算表就能更新網頁，不需重新部署。

```
06-travel/
├── index.html   # 網頁本體（單檔，含 CSS/JS、互動地圖與離線備援資料）
├── data.tsv     # 整理好的乾淨資料，貼到 Google Sheet 的 data 頁籤
└── readme.md
（images/ 為選用：若要放自己的插畫地圖圖檔再建立）
```

## 資料流

```
Google Sheet「data」頁籤  ──gviz JSON──▶  index.html 前端渲染
        ▲
   你編輯這裡（單一資料來源）
```

`index.html` 內也內嵌了一份相同資料當**離線備援**：當還沒建好 `data` 頁籤、
或試算表被改成私有時，頁面仍可顯示（狀態列會標示「離線備援資料」）。

---

## 步驟一：建立 data 頁籤（一次性）

1. 開啟試算表 → 左下角「＋」新增工作表，把它**命名為 `data`**（小寫，需完全相同）。
2. ⚠️ **先把整張設為純文字**：點左上角全選方塊（或 Ctrl/Cmd+A）→ 功能表 **格式 → 數值 → 純文字**。
   - 這步很重要：否則 Sheets 會把 `08:15`、`08:00~20:00`、`06/06` 等自動轉成時間/日期格式，
     gviz 讀到時無法解析的會變成空值，導致部分時間在網頁上消失。
3. 用文字編輯器開啟 `data.tsv`，全選複製。
4. 回到 `data` 頁籤，點 **A1**，直接貼上（Tab 分隔會自動分欄）。
5. 確認試算表分享設定為「**知道連結的任何人 → 檢視者**」（gviz 才讀得到）。

> 若你已經貼過、發現有時間不見了：把 `data` 整張設為純文字後，清空內容重貼一次即可。

### 資料欄位定義（共 9 欄）

| 欄 | 名稱 | 說明 |
|----|------|------|
| A | `type` | 列的種類：`day` / `schedule` / `meal` / `hotel` / `souvenir` / `flight` / `tip` / `map` |
| B | `day` | 日期，例 `6/6(六)`（schedule、meal、day 用，需與當日一致） |
| C | `category` | 分類：餐別(午餐/晚餐/下午茶)、伴手禮地區、tip 群組、航班(去程/回程/行李) |
| D | `time` | 時間，例 `08:15` 或 `08:00~20:00` |
| E | `title` | 主標題（行程名 / 店名 / 項目名 / 航線） |
| F | `transport` | 交通方式（schedule 用） |
| G | `duration` | 所需時間（schedule 用） |
| H | `url` | 連結（地圖 / 部落格，會變成卡片右側按鈕）；**`day` 列填這格＝當日頂部大圖網址**（可換成自己的照片） |
| I | `note` | 備註 / 摘要 / 說明文字 |

> 網頁採**單日切換**：頂部導覽列一次只顯示一天，點不同日期切換；行程當天會自動開到該日並標「今日」。每天有專屬主題色（D1紅／D2藍／D3綠／D4橙／D5紫），伴手禮獨立一頁。航班與出入境資訊掛在搭機當天（6/6、6/10）頁面底部。

### 當日景點地圖（互動式，自動產生）

每天行程下方有一張**互動地圖**（OpenStreetMap 底圖，非 Google）：
- 🔴 紅點＝當天行程景點；🟡 金點＝附近順遊（沒排進行程的鄰近景點）。
- 全繁體中文標註，可縮放、拖曳探索周邊街道與店家。
- 景點座標寫在 `index.html` 的 `DAY_SPOTS`（依日期）。要增刪景點就改這裡：
  ```js
  "6/8(一)":[
    {n:"渡月橋",lat:35.0130,lng:135.6776},          // 行程內
    {n:"金閣寺",lat:35.0394,lng:135.7292,near:1},   // 附近順遊(金點)
  ]
  ```
- 地圖需連線載入（Leaflet + 地圖磚走 CDN）；離線時會顯示提示、其餘內容照常。

> 仍保留圖片地圖功能（`type=map` 列填圖片 `url`）：若你之後有高解析插畫地圖，可放進 `images/` 並加 `map` 列，會顯示在互動地圖下方。

> ⚠️ **`data.tsv` 已更新**（修正欄位排版＋加入每日大圖）。若你先前已貼過舊版，請依步驟一把 `data` 整張設純文字後**清空重貼新版** `data.tsv`。

> 想新增一個景點：在對應日期插一列 `schedule`，填好時間、標題、交通即可，網頁會自動排進時間軸。
> 想換餐廳：改 `meal` 列的 `title` 與 `url`。

## 步驟二：本機預覽

直接用瀏覽器打開 `index.html` 即可（雙擊）。
若瀏覽器擋住 gviz 請求，會自動退回顯示離線備援資料——這是正常保護。

## 步驟三：部署到 GitHub Pages

```bash
cd /Users/daniel.sung/Desktop/Plan/06-travel

git init
git add index.html readme.md           # 若有自備地圖圖檔，再 git add images/；data.tsv 可不上傳
git commit -m "關西旅遊說明書"

# 在 GitHub 建一個 repo（例如 kansai-trip），然後：
git branch -M main
git remote add origin https://github.com/<你的帳號>/kansai-trip.git
git push -u origin main
```

接著到 GitHub repo → **Settings → Pages**：
- Source 選 **Deploy from a branch**
- Branch 選 **main** / 資料夾 **/(root)** → Save

約一分鐘後即可用網址開啟：

```
https://<你的帳號>.github.io/kansai-trip/
```

把這個網址傳給家人，手機就能看；之後改試算表 `data` 頁籤，重新整理網頁就更新。

## 常見問題

- **網頁顯示「離線備援資料」**：表示沒讀到 `data` 頁籤。檢查 (1) 頁籤名稱是否為 `data`、(2) 試算表是否為「知道連結的任何人可檢視」、(3) `index.html` 的 `SHEET_ID` 是否正確。
- **想換另一個試算表**：修改 `index.html` 最上方的 `SHEET_ID`。
- **時間欄變成奇怪數字**：gviz 會把純時間解析成時間值，本頁已優先採用顯示字串（`.f`），通常不會發生；若發生，把該格在 Sheet 設成「純文字」格式即可。
